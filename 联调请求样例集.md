# 录音文件转写 Agent - 联调请求样例集

> 供联调时快速验证各接口的正确性，覆盖正常流程与异常流程。

---

## 1. 能力查询（query_capabilities）

### 1.1 正常查询

**Request**
```bash
curl -X POST https://{gateway_domain}/runtimes/asr-agent/invocations \
  -H "X-Hw-Agentarts-Session-Id: s1" \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{"operation":"query_capabilities"}'
```

**Expected Response `200`**
```json
{
  "capabilities": {
    "chat_completions": true,
    "responses_api": true,
    "responses_get_fetch": true
  }
}
```

---

## 2. 创建异步转写任务（create_response）

### 2.1 正常创建（model_config 在 input 内）

**Request**
```json
{
  "operation": "create_response",
  "input": { "file_url": "https://asr-test-wav.obs.cn-southwest-2.myhuaweicloud.com/lfasr_涉政.wav" },
  "model_config": [
    {
      "type": "offline_asr",
      "provider": "openai-compatible",
      "endpoint": "https://convai-router/v2",
      "model_name": "ifasr",
      "auth_token": "Bearer <实际token>"
    }
  ]
}
```

**Expected Response `200`**
```json
{
  "response_id": "resp_xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "status": "in_progress"
}
```
> 记录返回的 `response_id`，用于后续 fetch_response 查询。

### 2.2 缺 input → 400 E4001

**Request**
```json
{"operation": "create_response"}
```

**Expected Response `400`**
```json
{
  "error": { "code": "E4001", "message": "create_response 缺少必填参数 input", "type": "invalid_request" }
}
```

### 2.3 无 operation 仅 input → 400 E4007（默认 chat_completions，本 Agent 不支持）

**Request**
```json
{"input": {"file_url": "https://.../test.wav"}, "model_config": [...]}
```

**Expected Response `400`**
```json
{
  "error": { "code": "E4007", "message": "本 agent 不支持同步对话...", "type": "capability_not_supported" }
}
```

---

## 3. 查询转写结果（fetch_response）

### 3.1 正常查询（进行中）

用 2.1 返回的 `response_id`，在创建后立即查询：
```json
{"operation": "fetch_response", "response_id": "resp_xxx"}
```

**Expected Response `200`**（大概率进行中）
```json
{ "id": "resp_xxx", "object": "response", "status": "in_progress" }
```

### 3.2 正常查询（已完成）

转写完成后（约 30-60s，依音频时长而定）再次查询。

**Expected Response `200`**
```json
{
  "id": "resp_xxx",
  "object": "response",
  "status": "completed",
  "output": [
    {
      "type": "message",
      "role": "assistant",
      "content": [
        { "type": "output_text", "text": "中新经纬7月15日电国家统计局15日公布数据..." }
      ]
    }
  ]
}
```
> 如未完成仍返回 `status: "in_progress"`，可重复查询。

### 3.3 缺 response_id → 400 E4001

**Request**
```json
{"operation": "fetch_response"}
```

**Expected Response `400`**
```json
{
  "error": { "code": "E4001", "message": "fetch_response 缺少必填参数 response_id", "type": "invalid_request" }
}
```

### 3.4 不存在的 response_id → 404 E4006

**Request**
```json
{"operation": "fetch_response", "response_id": "resp_not_exist"}
```

**Expected Response `404`**
```json
{
  "error": { "code": "E4006", "message": "响应不存在或已过期", "type": "response_not_found" }
}
```

### 3.5 已过期（>24h）的 response_id → 404 E4006

场景：需等 24h 或模拟过期，行为同 3.4。

---

## 4. 错误请求

### 4.1 未知 operation → 400 E4001

**Request**
```json
{"operation": "unknown_operation", "input": {}}
```

**Expected Response `400`**
```json
{
  "error": { "code": "E4001", "message": "未知的 operation: unknown_operation", "type": "invalid_request" }
}
```

### 4.2 非 dict 请求体 → 400 E4001

**Request**
```text
"just a string"
```

**Expected Response `400`**
```json
{
  "error": { "code": "E4001", "message": "请求体必须是 JSON 对象", "type": "invalid_request" }
}
```

## 5. 端到端回归测试序列（建议联调脚本按顺序执行）

```bash
# 1. query_capabilities
curl -X POST <gateway>/runtimes/asr-agent/invocations -H "..." -d '{"operation":"query_capabilities"}'

# 2. create_response（记录 response_id）
#    ⚠️ Session 亲和：create 与后续 fetch 必须用同一个 X-Hw-Agentarts-Session-Id（否则 404）
curl -X POST <gateway>/runtimes/asr-agent/invocations \
  -H "X-Hw-Agentarts-Session-Id: my-sess-001" -H "..." \
  -d '{"operation":"create_response","input":{"file_url":"<obs_url>"},"model_config":[{"type":"offline_asr","endpoint":"<router>","auth_token":"Bearer xxx"}]}}'

# 3. 立即 fetch（预期 in_progress；同一 Session-Id）
curl -X POST <gateway>/runtimes/asr-agent/invocations \
  -H "X-Hw-Agentarts-Session-Id: my-sess-001" -H "..." \
  -d '{"operation":"fetch_response","response_id":"<resp_xxx>"}'

# 4. 30s 后 fetch（预期 completed 或 in_progress；同一 Session-Id）
sleep 30
curl -X POST <gateway>/runtimes/asr-agent/invocations \
  -H "X-Hw-Agentarts-Session-Id: my-sess-001" -H "..." \
  -d '{"operation":"fetch_response","response_id":"<resp_xxx>"}'

# 5. 不存在的 response_id（预期 404）
curl -X POST <gateway>/runtimes/asr-agent/invocations -H "..." \
  -d '{"operation":"fetch_response","response_id":"resp_not_exist"}'

# 6. 无 operation 默认（预期 200 chat.completion，阻塞至转写完成）
curl -X POST <gateway>/runtimes/asr-agent/invocations -H "..." \
  -d '{"input":{"file_url":"<url>"}}'

# 7. 未知 operation（预期 400 E4001）
curl -X POST <gateway>/runtimes/asr-agent/invocations -H "..." \
  -d '{"operation":"unknown","input":{}}'
```
